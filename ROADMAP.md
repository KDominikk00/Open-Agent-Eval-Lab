# Roadmap

- Add model adapter retries and rate-limit backoff for API-backed agents.
- Add optional result caching keyed by task/model parameters.
- Add per-difficulty and per-grader performance breakdowns.

- Add agent profile configuration files (YAML/JSON).
- Add plugin interface for external tool simulators.
- Add richer leaderboard filtering and trend charts.

## Longer-term (v1.0)

- Add benchmark packs focused on PR review and code-quality triage.
- Add signed benchmark snapshots and reproducibility manifests.
- Publish baseline benchmark reports on a regular cadence.
